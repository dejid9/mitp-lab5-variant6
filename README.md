## Выполненные практические задания по варианту 6

### Средней сложности
1. **№2 — Окно с текстовым полем и кнопкой, выводящей текст.** Создана вкладка в графическом приложении Tkinter (`src/app_gui.py`) с виджетом текстового ввода `ttk.Entry`, кнопкой `ttk.Button` и динамической меткой `ttk.Label` для вывода введённого текста.
2. **№6 — Прогрессбар.** Интегрирован виджет `ttk.Progressbar` с кнопками пошагового заполнения (+20%), плавной анимации выполнения и сброса, а также текстовым индикатором процентов.
3. **№8 — Диалог выбора файла.** Реализован выбор файлов через стандартный диалог `filedialog.askopenfilename()` с отображением выбранного пути и предпросмотром текстового содержимого в области прокручиваемого текста.

### Повышенной сложности
1. **№4 — График matplotlib внутри Tkinter.** Реализована интеграция библиотеки `matplotlib` с холстом Tkinter через бэкенд `FigureCanvasTkAgg` (`src/canvas_plot.py`). В интерфейсе доступно интерактивное переключение функций ($y=x^2$, $y=\sin(x)$, $y=x^3$) и перерисовка графика в реальном времени. Демонстрационный снимок графика сохранён в `canvas_demo.png`.
2. **№10 — Программа чат (локальный).** Реализована полнофункциональная клиент-серверная подсистема локального чата:
   - Встроенный в GUI чат с выбором псевдонима, лентой сообщений и отправкой по клавише Enter;
   - Многопоточный TCP-сокет сервер `src/chat_server.py` для обмена сообщениями между несколькими клиентами;
   - Модуль протокола и форматирования сообщений с временными метками `src/chat_protocol.py`.

## Установка и запуск

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Запуск графического интерфейса
python main.py

# Запуск консольного/CI демо-режима
python main.py --headless

# Запуск сервера локального чата (в отдельном терминале)
python -m src.chat_server

# Проверка линтером и тесты
python -m flake8 .
python -m pytest -v
```

### Linux / macOS (Bash)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Запуск GUI (требуется графический сервер X11/Wayland)
python3 main.py

# Запуск консольного демо-режима
python3 main.py --headless

# Проверка стиля кода и запуск тестов
python3 -m flake8 .
python3 -m pytest -v
```
